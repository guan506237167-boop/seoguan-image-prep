# 关山阅SEO网页图片压缩与命名

批量把静态图片缩放为WebP副本，输出尺寸、体积和原文件映射。适用于网站与内容配图准备，保留原图和透明度。

**业务环节：04 内容生产**

## 输入与输出

输入：输入目录、全新输出目录、最大边长与质量；用户可选业务文件名前缀。

输出：新目录中的WebP副本与manifest.json（原名/新名/尺寸/字节/状态），可交给内容或网站负责人。

## 工作步骤

1. 确认输出目录全新，文件按名称排序；脚本保留输入，不删除文件，不递归扫描其他目录。
2. 安装 requirements.txt 中的Pillow后运行 scripts/prepare_images.py；修正EXIF方向、保留透明通道，不放大小图。
3. 动画、无法读取或不支持色彩模式的文件按文件记录跳过/失败；不能偷偷只保留动画第一帧。
4. 检查manifest中尺寸、体积和映射，压缩后变大也如实记录。脚本删除EXIF等隐私元数据，保留ICC色彩配置（若有）。
5. 需要语义文件名或alt时依据实际图像内容另做建议；不能只看文件名编造画面。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-image-prep`。支持 `$技能名` 的宿主可使用下方示例。

依赖：Python 3.10 或以上；图片处理另需 Pillow >=12.2,<13。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。

本工具附带本地脚本，请先阅读[脚本用法与样例](references/script-usage.md)。
